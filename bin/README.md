# Archived legacy stories

This folder preserves the original story files whose English light-novel adaptations now live in the Tidewritten Library.

Archived source groups:
- Nayi Chidiya / Notun Pakhi (Seasons 1–3) → The Little Bird Chronicles (Volumes 1–3)
- Phir Milenge (Seasons 1–3) → Meet Again Trilogy (Volumes 1–3)
- X-Prismat (English and Hinglish editions) → Prismat: Fragments of the Fallen Sky

These files are kept for reference and are not part of the reader-facing story collection. The adapted editions are the versions linked from the homepage and Library.
